## 3. 個別の重大な取りこぼし

### 3-1. ブランド名「AIの鬼」を自サイトが取れていない

「aiの鬼」= 20表示・5クリック・**平均順位6.2**。しかも内訳が異常：

| クエリ | 着地ページ | 表示 | クリック | 順位 |
|---|---|---|---|---|
| aiの鬼 | `/shippai/` | 18 | 4 | 8.7 |
| aiの鬼 | `/naka/` | 7 | 2 | **2.6** |
| aiの鬼 | `/`（トップ） | 4 | 0 | 7.2 |
| aiの鬼 閉鎖 | `/shippai/` | 2 | 0 | 2.5 |
| 鬼ai | `/articles/ai-what-is-oni/` | 3 | 0 | 3.0 |

**トップページ（7.2位）が下層ページ（2.6位）に負けている。** 原因は2つ：

1. **同名の先行アカウントが名前を占有している。** 「AIの鬼」はAIイラスト作家の名義として [pixivFANBOX](https://ai-demon-02.fanbox.cc/) / [BOOTH](https://ai-demon.booth.pm/items/6483977) / [note](https://note.com/aidemon) に既に存在し、さらに [AI鬼管理](https://genai-ai.co.jp/ai-kanri/service/) という近接サービス名もある。「aiの鬼 閉鎖」という検索が来ているのも、おそらくこの先行アカウントを探している人。**ブランド名が競合している**という前提で戦う必要がある。
2. **トップページのtitle/h1にブランドの主張がない。** title は `AIニュース・研究動向 · AIの鬼`（[base.html:6](../aioni/templates/base.html#L6) の `{% block title %} · {{ site_name }}` 構造）でブランド名が末尾。h1 は `語るより、動かす／鬼の仕事、隠さず報告` でブランド名も業種語もゼロ。

### 3-2. 順位1.6位で0クリック — 最大の1件

| クエリ | 着地ページ | 表示 | クリック | 順位 |
|---|---|---|---|---|
| **kimi k3 使い方** | `/news/zenn_ai-d8ccad58e5/` | 10 | **0** | **1.6** |

ほぼ1位を取っているのに10回連続でクリックされていない。理由は明白で、**このページのtitleがZennの元記事タイトルそのまま**だから。同じタイトルが2つ並べば、読者は原典を選ぶ。「Kimi K3 使い方」は明確に実務意図のあるクエリで、実測ラボが最も得意な形に落とせるのに、集約スタブが席を占領して機会を殺している。

### 3-3. 商用意図クエリが、全部ニュース集約ページに当たっている

| クエリ | 着地ページ | 順位 |
|---|---|---|
| ai研修 法人 選定 | `/news/ainow-811689cb2e/` | 90.3 |
| 生成ai 開発会社 | `/news/ainow-33fa5e7a0b/` | 68.0 |
| ai エージェント 営業 | `/news/ainow-e70bea36e5/` | 90.0 |
| ai 開発 費用 相場 | （articles/ai-cost-structure 系） | 95.0 |
| ai 導入 費用 | 〃 | 98.0 |
| ai開発 見積もり 費用 内訳 | 〃 | 100.0 |
| ai面接 バイアス 対策 | `/news/mit_tr-64de944135/` | 87.7 |

**TOEの本業（製造業AIコンサル）に直結する唯一の金脈クラスタが、90〜100位。** かつ着地が自社の一次記録ではなく他社ニュースの要約ページ。`/articles/ai-cost-structure/` は7表示・順位97。

### 3-4. `/papers/` に個別ページが1枚も無い

`/papers/` 配下はサイトマップ上も9枚＝`/papers/`〜`/papers/8/` の**ページネーションだけ**。個別論文ページが存在しない。にもかかわらず表示の23.2%を吸い、CTRは1.7%。arXivのタイトル語でリストページが当たっており、クリックしても読者は「一覧」に着地して答えが無い。`/papers/8/` は `index, follow` のまま。

### 3-5. 他社媒体名でソース別アーカイブが当たっている

「the verge ai」で `/news/source/verge_ai/` が**5.7位**。他媒体のブランド名で自社アーカイブが上位に出るのは、読者価値がなく、商標面でも避けたい。このページも `index, follow`。

## 5. 改善案（実行順）

### 優先1｜ブランド「AIの鬼」を自サイトが取る（今週）

1. トップページの `<title>` を `AIの鬼 | 中小企業のAI実践・実測ラボ（株式会社TOE）` に。ブランド名を先頭へ
2. トップの `h1` にブランド名と業種語を入れる（キャッチコピーは `p` か `h2` に降ろす）
3. Organization JSON-LD に `alternateName: "AIoni"` と `sameAs`（X・note・gtoe.info）を追加。同名の別人格と切り分ける材料をGoogleに渡す
4. `/about/` に運営者情報（株式会社TOE・所在地・執筆体制）を実名で厚くする（E-E-A-T兼ブランド識別）
5. 指名検索を自分で作る：X・note・メール署名・名刺で必ず「AIの鬼（ai-oni.com）」とドメイン併記

### 優先2｜1.6位0クリックを回収する（今週）

1. **「Kimi K3 使い方」で実測記事を1本書く。** TOEが実際に触ったログ・所要時間・失敗込み。`/news/zenn_ai-d8ccad58e5/` から新記事へ内部リンク
2. これを型にする：**順位10位以内かつクリック0のクエリを毎週抜き出し、実測記事に転換する運用**にする（今回の該当は他に「hymobileagent」9.3位、「jaxa api」9.5位、「google ナレッジ」8.0位、「promptsref」8.0位）

### 優先3｜ニュース648本のCTRを直す（コード修正・1回で全件効く）

1. **title を原文コピーから自社視点に変える。** 例: `{原文タイトル}｜中小企業の実務でどう効くか — AIの鬼`。原典と同一タイトルで並ぶ状態をやめる
2. **description を要約本文の冒頭から生成**（[build.py:658](../aioni/build.py#L658)）。title丸写しをやめる
3. base.html に `{% block description %}` を追加するか、news_article.html の死んだブロックを消して build 側で渡す（欠陥C）
4. **NewsArticle JSON-LD を追加**（headline / datePublished / author=AIの鬼編集部 / publisher=株式会社TOE / isBasedOn=出典URL）。`isBasedOn` で「要約であって原典ではない」を機械可読に明示できる
5. **全テンプレートの `alt=""` を埋める**（欠陥A）。記事は記事タイトル、ニュースは「{出典媒体}が報じた{見出し}」で機械生成可

### 優先4｜商用意図クラスタを本気で取る（今月）

memory [AEOは量産でなく既存強化](../../.claude/projects/-Users-kojimajouji/memory/feedback_aeo_content_strategy.md) に従い、新規量産ではなく既存強化：

1. `/articles/ai-cost-structure/`（現3,704字・順位97）を**費用クラスタのハブ記事に育てる**。TOEが実際に見積もった実額レンジ、初期／連携／運用の内訳表、月額の実測、失敗して高くついた例。数字は[一次情報で裏取り](../../.claude/projects/-Users-kojimajouji/memory/feedback_verify_numbers.md)
2. 「ai 開発 費用 相場」「ai開発 見積もり 費用 内訳」「生成ai 開発会社」を**このハブ1本に集約**（共食い回避）
3. 該当する `/news/ainow-*` からハブへ内部リンクを張る。集約ページが吸っている表示をハブへ流す
4. 同様に「AI研修 法人 選定」「AIエージェント 営業」も、TOEの実案件記録があるなら1本ずつ

### 優先5｜低価値ページの整理（今月）

1. `/papers/2/`〜`/papers/8/`（ページネーション）を `noindex, follow` に。表示23%を吸ってCTR1.7%なら、サイト全体の評価を薄めている
2. 注目論文だけ**個別ページ化**（arXiv要旨＋TOEの読み解き＋中小企業への含意）。これはやれば `/papers/` が資産に変わる
3. `/news/source/*/`（媒体別アーカイブ）を `noindex, follow` に。「the verge ai」で5.7位は取ってはいけない順位
4. 記事212本のうち149本（70%）が検索に一度も出ていない。**トピッククラスタの内部リンクを張る**（ハブ記事→個別記事→ハブ）
5. 60日経っても表示0のニュースは、トピック単位のまとめ記事へ統合して個別ページを畳む検討

### 優先6｜計測の穴を閉じる（今週）

1. **GA4がAPIから読めない。** ADCのスコープに `analytics.readonly` が無く403。流入元・回遊・`/contact/` 到達が全く測れていない。1回だけ対話実行が必要：
   ```
   gcloud auth application-default login \
     --scopes=https://www.googleapis.com/auth/webmasters.readonly,https://www.googleapis.com/auth/analytics.readonly,https://www.googleapis.com/auth/cloud-platform
   ```
   その後 GA4 Data API を週次レポートに合流させる
2. **修正済み**: `tools/searchconsole_report.py` のレポートファイル名にサイト名が入っておらず、uchuchu.tech の実行が ai-oni.com の 07-29 レポートを上書きしていた。`searchconsole_{サイト}_{日付}.md` に変更
3. Bing Webmaster 登録と IndexNow 送信の有無を確認（未検証）
4. デスクトップ表示81%／モバイルCTR2倍の乖離を、GA4が繋がったらデバイス別の回遊で追う
