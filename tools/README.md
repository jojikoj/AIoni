# tools/

## 案件獲得のためのツール（2026-08-01 追加）

AIの鬼の目的は記事のPVではなく、**AEO案件とAIエージェント案件の受注**。
検索流入を待つだけでは商談にならないので、こちらから名指しで動くための道具を置いている。

| ツール | 何をするか |
|---|---|
| `batch_visibility.py` | 企業リスト(CSV)のAI可視性を一括実測し、`data/visibility/<batch>.json` に貯める |
| `gen_ranking_article.py` | その実測から業界別ランキング記事を組み立てる（`content/articles/` へ） |
| `gen_company_report.py` | 1社ぶんの実測レポート(HTML/PDF)と、送付メールの下書きを作る |
| `demo_agent/agent.py` | 製造業向けAIエージェントの実演。提案の場でそのまま動かす |

### 流れ

```
公開名簿から企業リストを作る          data/companies/<batch>.csv
        │                            （母集団の作り方は同ディレクトリのREADME）
  batch_visibility.py --dry-run       件数と費用を確認（必ず先に）
  batch_visibility.py                 実測（逐次保存・途中再開できる）
        ├── gen_ranking_article.py    記事 → 集計だけ公開。悪い結果の社名は出さない
        └── gen_company_report.py     1社ごとのレポート＋メール下書き → 個別に送る
```

**記事とレポートで扱いを分けているのが肝。**
記事は集計値と上位企業だけを公開し、結果の悪かった企業名は伏せる。
その企業には個別にレポートを送る。褒める相手にも、直したい相手にも、
どちらにも連絡する正当な理由ができる。

## 問い合わせ受付について

**このメディア専用のGASは置かない。**

問い合わせ受付は**コンテンツ部の共通GAS**を使う。
メディアごとに同じ仕組みを作ると、デプロイもURL管理も二重になるため。

- 実体: `claude_AIR/TOEcompany/コンテンツ部/共通/gas/受付.gs`
- 手順: `claude_AIR/TOEcompany/コンテンツ部/共通/gas/設置手順.md`

かつてここに `form_receiver.gs` を置いていたが、共通版に統合して削除した（2026-07-18）。

## 現在の接続先

サイトのフォーム送信先は `aioni/config.py` の `FORM_ENDPOINT` で決まる。

| 状態 | 値 |
|---|---|
| 現在 | FormSubmit（外部サービス・有効化済み・稼働中） |
| 移行先 | 共通GASのウェブアプリURL（デプロイ後に差し替える） |

共通GASをデプロイしたら、`FORM_ENDPOINT` をそのURLに変更するだけで切り替わる。
