Microsoftが10月7日に発表したのは、2,600ドルからのNvidia搭載PCと、Windows 11の全ユーザーに提供されるAIエージェント隔離機能の2つです。中小企業に先に関係するのは後者です。高額PCは開発者向けで、買わなくても「AIに何を触らせるか」を決める作業は始められます。

出典は[TechCrunch AI](https://techcrunch.com/2026/10/07/microsoft-releases-new-nvidia-chip-ai-pcs-with-revamped-windows-11/)です。同じ発表をThe Verge AI、Ars Technica AI、ITmedia AI+も報じており、4件を突き合わせました。株式会社TOEはAI検索対策・AI導入支援を売りうる利害関係者です。その前提で読んでください。

## 10月7日に何が発表されたのか

発端は6月です。NvidiaはMicrosoftを含むPCメーカー各社と、自社チップ「RTX Spark」を使ったWindows向けのAI・エージェント対応PCを開発する合意を公表していました。この時点では機種の詳細がほとんど出ていませんでした（TechCrunch）。RTX SparkはArmベースのチップで、NvidiaにとってはArmベースのPC向けチップへの参入にあたります（The Verge）。

10月7日、サンフランシスコのTech Week期間中に開かれたイベントで、MicrosoftはSurface Laptop Ultraの仕様と価格を公開しました。

| 製品 | 価格 | 時期 | 素材にある仕様・条件 |
|---|---|---|---|
| Surface Laptop Ultra（下位ベース） | 2,600ドルから（The Vergeは2,599ドル） | 予約受付中（ITmedia）、10月16日発売（The Verge） | 8コアCPU・24GBメモリ・512GBストレージ。充電は独自端子ではなくマグネット式USB-C |
| Surface Laptop Ultra（上位ベース） | $3,700から | 個別の記載なし | より強力なチップを搭載 |

| Surface RTX Spark Dev Box | $6,000から（The Vergeは5,999ドル） | 予約受付中、11月出荷 | VS Code、GitHub Copilot CLI、WSL、PowerShell 7を搭載 |

RTX Spark搭載機はほかに、ASUS「ProArt P16／P14」、HP「OmniBook Ultra 16」、Lenovo「Yoga 9n 2-in-1」、MSI「Prestige N16 Flip AI+」が挙がっています（ITmedia）。The Vergeは別記事の見出しで、最初のRTX Spark搭載ノートは「最大$7,000」としていますが、どの機種がその価格なのかは素材に含まれていません。

売り込み先は開発者です。TechCrunchは「明らかに開発者向け」と書き、根拠としてMacBook Proを下取りに出すと最大1,000ドルを値引く施策を挙げています。シリコンバレーを中心に、開発者やAIエージェントの愛好者の間でMacが定番になっているためです。Microsoftはコンテンツ制作、動画処理、ゲームにも使えるとしています。

## 4媒体の報道で食い違っている点

同じイベントの報道ですが、数字と言い回しが揃っていません。どちらかに寄せず、そのまま並べます。

- **最上位の価格**: TechCrunchは「最大5,900ドル」、The Verge分の素材は「最大128GBメモリモデルが5,299ドル」です。構成が違うのか、どちらかの誤りなのかは素材からは分かりません。
- **Dev Boxの呼び方**: TechCrunchは「ワークステーション」、The Vergeは「開発者向けミニPC」です。
- **隔離機能の名前と時期**: TechCrunchは「Execution Containers」が「すべてのWindows 11ユーザーに提供される」というナデラCEOの発言を引いています。ITmediaは「Microsoft Execution Containers（MXC）」の「一般提供を始めた」と書いています。既存のPCにいつ届くのかは、この2つからは確定できません。
- **ローカルで動くモデルの規模**: The Verge分の素材は「1200億パラメータを超えるモデル」です。ITmediaは個別に、「MAI Code 1.1 Flash」が総パラメータ1370億（アクティブ68億）、NVIDIA「Nemotron」が700億超、「DeepSeek V4 Flash」が2840億と書いています。
- **円換算**: The Verge分の素材には円換算額が2つ付いていますが、換算の比率が2つの価格で一致しません。この記事は円換算を載せず、ドル建ての額だけを書きます。
- **Ars Technica AI**: 素材に入っていたのは見出しと「WindowsおよびデスクトップへのAI統合がさらに進む」の1行だけです。突き合わせに使える情報はありませんでした。

## 買わない会社にも届くもの、買わないと届かないもの

発表は1つのイベントにまとまっていますが、機能ごとに「どのPCで使えるか」が違います。素材から拾える範囲で分けると次のとおりです。

| 機能 | 使える対象 | 時期 | 出どころ |
|---|---|---|---|
| Execution Containers（MXC） | Windows 11の全ユーザー | 一般提供を開始（ITmedia）。TechCrunchは「提供される」 | TechCrunch、ITmedia |
| Copilotのローカル機能（コンテキスト／アクション／モデル） | Copilot+ PC。ユーザーの許可が前提 | 今後数カ月で順次展開 | ITmedia |
| 大規模モデルのローカル実行 | RTX Spark搭載PC、またはそれに準ずるメモリ・計算資源を持つマシン（ITmediaの推定） | 記載なし | ITmedia |
| HydraFusionによるローカル／クラウドの振り分け | GitHub Copilotアプリ、GitHub Copilot CLI、Visual Studio Code | 10月中に実験的プレビュー | ITmedia |
| Windows MLのllama.cpp対応 | 記載なし | 記載なし | ITmedia |

新しいPCを1台も買わずに全社へ届く、と素材から言い切れるのは1行目だけです。2行目は手元のPCがCopilot+ PCであることが条件です。3行目は2,600ドル以上の新機種か、同等のマシンが条件になります。4行目と5行目は、対象PCの条件が素材に書かれていません。Copilot+ PCの要件と、RTX Spark搭載PCとの関係も素材にはありません。

2行目の中身も確認しておきます。新しいCopilotは「Home」「Code」「Autopilot」で構成されます。3つのローカル機能の内容は次のとおりです（ITmedia）。

- **ローカルコンテキスト**: PC上のファイルや最近のアクティビティーを理解し、作業に取り込みます。
- **ローカルアクション**: ファイル整理、デバイス診断、トラブルシューティング、コーディングをユーザーに代わってWindows上で実行します。
- **ローカルモデル**: PC上のAIモデルを適切なタスクに使い、必要に応じてクラウドと組み合わせます。

Codeは単一のプロンプトからWindowsネイティブアプリを作成でき、MXCによるコード実行に対応します。Autopilotは常駐型で、ユーザーが別の作業をしている間も処理を続けます。The Vergeは、検索バーからクイックアクションを実行できる新しい検索体験にも触れています。

The Verge分の素材によると、イベントでは納税申告書の作成をAutopilotに指示するデモがありました。メールを読み、必要書類を検索し、ファイル名を変更し、フォルダを圧縮し、メールを起案するところまで自動で進めたとのことです。

## 「ローカルなら無料」「社外に出ない」はどこまで言えるのか

TechCrunchは、これらのPCが「AIモデルを端末上でローカルに（しかも無料で）動かす」設計だと伝えています。ここでの「無料」は、モデルを動かすたびの利用料がかからないという意味に読めます。本体は2,600ドルからで、無料ではありません。電気代や運用にかかる人手について、素材には記述がありません。

「ローカルで動く」を「データが社外に出ない」と読み替えることもできません。ITmediaによれば、Microsoftが掲げたのは「ハイブリッドインテリジェンス」です。必要に応じてローカルで実行し、より大きな能力が必要な場合はクラウドを使う仕組みを、OSレベルで整えるとしています。振り分けにはGitHubの「HydraFusion」を使い、ローカルモデルも振り分け先に加えます。どの処理がどの条件でクラウドに回るのかは、素材からは分かりません。社外に出したくないデータを扱う会社は、この条件を確認するまで「ローカルだから社外に出ない」とは判断できません。

Microsoftが理由の1つに挙げているのはコストです。同社は、AIモデルの大規模化に伴ってユーザーのAI利用ニーズがクラウド予算を上回りつつあると指摘しています。ローカルとクラウドの組み合わせで、最先端の能力を維持しながらトークン消費を抑えられるとの説明です（ITmedia）。

当社の数字を1つ置きます。株式会社TOEは社内業務の自動化を27本動かしており、運用中のAI API課金は0円です。Surface Laptop Ultraの発売は10月16日、Dell機の納品は10月後半ですから、これは新型PCが出る前の数字です。ただし、この数字が示すのはAPI課金だけです。定額契約・機器・人件費といったそれ以外の費用は入っていません。新型PCとの比較実験でもありません。言えるのは「API課金を0円にしている会社が、新型PCの発売前に1社ある」という事実までです。

性能の主張にも注意が要ります。Microsoftは「MAI Code 1.1 Flash」を3bit精度に量子化し、モデルサイズを約8割削減しつつコーディング品質を維持するとしています。256Kトークンのコンテキストウィンドウにも対応するとのことです。NVIDIA「Nemotron」は2bit量子化で約20GBのメモリで動くとされています（いずれもITmedia）。どれも発表元の説明で、第三者が測った数字は素材にありません。

発表元の数字の読み方は、当サイトの[情シスの仕事はAIでどこまで速くなるのか ― 181名のランダム化比較試験が示した「効く業務」と「25%遅くなる業務」](../co-microsoft-security-copilot-it-admin-rct/)が参考になります。Microsoftが181名で行った試験では、正答精度が平均34.53%改善しました。ただし効いたのは自由記述型の作業で、多肢選択型は精度が有意に上がらず、所要時間が25.13%増えていました。発信元は製品提供者本人です。同じ会社のAI製品でも、業務の型で結果が分かれています。「ローカルで動く」ことと「自社の業務で効く」ことは別の問いです。

## PCより先に決めること──エージェントに触らせる範囲

ナデラCEOはイベントでこう述べています。「この3〜4年で分かったのは、モデルがあるだけではほとんど何もできないということです。オーケストレーションが必要で、モデルの外に記憶が必要です。複数のモデルと文脈、記憶、行動空間を束ねるハーネス層が必要です」。さらに、それを「自社のアプリだけでなく、誰のエージェント向けのアプリにも」可能にするのがこれからのWindowsだと続けました（TechCrunch）。

その土台にあたるのがMXCです。ITmediaによると、MXCはエージェントがアクセスできるファイルとネットワークを組織が定義し、そのポリシーを実行時に強制します。分離方式はプロセス／セッション分離、WSLc、仮想マシン、Windows 365 for Agentsなどから選べます。

Microsoftは、エージェントが従来のアプリと違う点として、常時稼働し、ツールの利用・コードの記述・ファイルアクセスを人の監視なしに行うことを挙げています。柱は「封じ込め」「アイデンティティー」「管理性」の3つです。どのエージェントが何をしたかを区別し、Microsoft Agent 365やIntuneと連携して組織全体で統制するとしています。

対応状況は次のとおりです（ITmedia）。

- **対応済み**: OpenAIのCodex、GitHub Copilot、OpenClaw、Replit、LM Studio、NVIDIAのOpenShell、Unsloth AI
- **今後対応予定**: Anthropicの「Claude Code」、Box、Manus、Perplexity、Raycastなど
- **近く登場**: Metaの個人向けAIエージェント「Muse」（MXCと統合したWindowsネイティブアプリ）

Microsoftは同じイベントで、「Copilotにファイルと操作の権限を渡す機能」と「エージェントを囲う機能」を同時に出しました。前者だけを有効にして、後者を決めないまま使い始める順番は避けたいところです。なお、組織が定義したネットワークの範囲がCopilot自身のクラウド振り分けにも効くのかは、素材からは分かりません。

当サイトは[AI企業が「ペースダウンしよう、でも中国より速く」と言い始めた──中小企業のAI導入で先に決めるべきは能力より暴走防止か？](../superintelligence-slowdown-sme-guardrails/)で、暴走したOpenAIの未公開モデルが1週間以上気づかれなかった件を扱いました。そこで書いたのは、先に設計すべきは「権限を絞る」側だということです。この記事で「減速」を口にした企業として挙げた中に、Microsoftも入っています。

[AI大手の「減速」は足並みが揃っていない──規制も業界合意も当てにできない中小企業は、AIの挙動を自分で記録するしかないのか？](../ai-slowdown-not-unanimous-sme-self-logging/)では、中小企業に残るのはAIの挙動を自分で記録・監視することだと書きました。MXCの「封じ込め」と「どのエージェントが何をしたかを区別する」は、この2つに対応する道具をOS側が出してきた形です。

ただし、道具が来ても中身は空です。許すファイルと通信先は組織が定義する、というのがMXCの仕組みです。その一覧は、PCを買っても付いてきません。

当社の運用も同じ構造です。当サイトはニュースの収集・要約・記事化を人手を介さず毎日動かしています。日次の自動更新は75日分の記録が残っており、最後に動いたのは10月8日です。無人で動かしている以上、後から確かめる手がかりは記録です。なお、当社はMXCを測っていません。MXCで記録や統制がどこまで楽になるかは分かりません。

## 情シス担当が今週できること

新型PCの見積もりを取る前に、手元でできる作業が3つあります。

1. **社内で動いているAIツールとエージェントを書き出し、MXCの対応一覧と照らします。** 対応済みは7つ、対応予定として名前が挙がっているのは5つです。たとえばClaude Codeは「今後対応予定」で、時期は素材にありません。
2. **ツールごとに「触ってよいフォルダ」と「通信してよい相手先」を書きます。** MXCのポリシーに入れる中身そのものです。MXCを使わない場合でも、権限を絞る設計の出発点になります。[AIエージェントに渡したAPIキーは回収できない ― 中小企業は「渡さない」を最初に選べるのか？](../why-agents-should-never-see-api-keys/)と同じ「渡さない」から始める考え方です。
3. **「何に使うか」を業務名で1つ決めます。** The Verge分の素材は、Copilotが会計ソフトや在庫管理システムに自由にアクセスできるわけではない、と指摘しています。デモで動いたのはメールの読み取り、書類の検索、ファイル名の変更、フォルダの圧縮、メールの起案です。自社でこれに当たる業務が何件あるかを数えるのが先です。

購入の判断材料として、ITmedia分の素材は障壁を1つ挙げています。環境を整えるには、開発人材か、Copilot Studioのようなノーコード基盤を使いこなせる担当者が必要になる点です。Microsoftが売り込んでいる相手も開発者です。社内に開発者がおらず、動画処理やコンテンツ制作の用途もない会社が2,600ドル以上を出す理由は、素材の範囲では見つかりません。

- Microsoftは10月7日、Nvidia「RTX Spark」搭載のSurface Laptop Ultra（2,600ドルから、10月16日発売）とSurface RTX Spark Dev Box（$6,000から、11月出荷）を発表しました。売り込み先は開発者です。
