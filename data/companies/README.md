# 実測対象の企業リスト

`tools/batch_visibility.py` に食わせる CSV を置く。

## 列

| 列 | 必須 | 用途 |
|---|---|---|
| `name` | ✅ | 会社名。**この文字列をそのままAIに尋ねる**ので、正式表記で書く |
| `url` | | 公式サイト。実測には渡さない（渡すと答えを教えることになる）。レポートの突き合わせ用 |
| `product` | | 主力製品・サービス。同名他社と切り分けたいときだけ入れる |
| `industry` | | 業界名。記事の見出しに使う |
| `pref` | | 都道府県 |
| `contact` | | 問い合わせフォームのURL。通知メールを送るときに使う |
| `note` | | メモ |

## 母集団の作り方（ここが記事の信頼性を決める）

**「誰でも同じリストを再現できる」ことを最優先にする。**
自分で恣意的に選んだ50社では、結果が良くても悪くても「選び方でどうにでもなる」と言われて終わる。

良い母集団:

- 業界団体・企業ネットワークの**公開会員名簿**（掲載順にすべて取る。抜かない）
- 公的機関の企業ガイド・支援先一覧
- 工業団地の入居企業一覧

避ける母集団:

- 検索結果の上位N社 … 検索で上位に出る＝すでに発信できている企業に偏る。
  「AIに認識されている率」が実態より高く出る（**測りたいものが測れなくなる**）
- 自分で選んだ「良さそうな会社」 … 恣意的。記事の前提が崩れる

CSVの先頭に、**出典URLと取得日をコメント行（`#` 始まり）で必ず書く。**
記事側でも母集団の出どころを明示する。

## 実在の確認

社名は必ず一次情報（名簿・公式サイト）から写す。**推測で社名やURLを補わない。**
確認できない列は空のままにする。空欄は害がないが、間違った情報は記事全体の信用を消す。
