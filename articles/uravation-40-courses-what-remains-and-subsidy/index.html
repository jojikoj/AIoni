法人AI研修「全40コース」は受講後に何が手元に残り、助成金は本当に使えるのか？

Uravationが2026年8月25日、8職務×5つのAI環境で選ぶ法人向け生成AI研修「全40コース」を提供開始しました。今回は「受講後に何が手元に残るか」と「人材開発支援助成金は使えるのか」に絞って素材を読み解きます。12時間コースと6時間ライト版の違い、助成対象の条件、そして当社がClaude Codeで社内自動化27本を回している実測と突き合わせ、中小企業が損しない見方を整理します。

AIの鬼 編集部2026年9月5日

株式会社Uravationが2026年8月25日に提供開始した法人向け生成AI研修「全40コース」について、今回は「受講後に何が手元に残るのか」と「人材開発支援助成金は使えるのか」の2点だけを掘ります。結論を先に言うと、素材には残る成果物のリスト（テンプレート集・成果物の実物・運用ルール案・展開ロードマップ）と助成の条件（12時間コースは対象になりうる／6時間ライト版と役員分は対象外）が具体的に書かれています。一方で、効果や定着率の数字は素材にも当社の測定にもありません。ここは埋めずに「分からない」と書きます。

なお当社（株式会社TOE / AIの鬼）は、AI検索対策・AI導入支援を売りうる利害関係者です。以下は自社商品を良く見せるためではなく、実測に照らして読者が損しない判断のための整理として読んでください。

まず前提：全40コースは「職務×AI環境」の掛け合わせ

素材（ASCII.jp）によれば、Uravation（東京都文京区・代表取締役 佐藤 傑）は8職務と5つのAI環境を掛け合わせ、全40コースとして体系化しました。8職務は、経理・財務・労務／人事・採用・総務／営業・提案・カスタマーサクセス／企画・マーケ・広報／製造・物流・現場管理／接客・サービス・ケア職／士業・法務／管理職・経営層。5つのAI環境は、ChatGPT（OpenAI）／Claude（Anthropic）／Gemini（Google）／Microsoft Copilot（Microsoft）／Claude Code（Anthropic）です。

コース名は「○○向け生成AI業務活用コース for（AI名）」で、Claude Code列だけ「○○向けAIエージェント自動化コース for Claude Code」。累計4,000名以上・100社以上（2026年8月時点・同社実績）の研修経験をもとに、12時間研修を職務モジュール8種とAI操作モジュール5種の組み合わせに再編したものです。全体像の読み解きは既存記事職務×社内AIで選ぶ「全40コース」の法人AI研修は、中小企業の「Copilotしか使えない」を解けるのか？に譲り、本記事は「受講後」と「助成金」に集中します。

受講後に手元に残るもの（素材にあるリスト）

研修は「受けて終わり」になりがちですが、素材は手元に残る成果物を具体的に列挙しています。通常コースと「for Claude Code」コースで残るものが違う点が実務的に効きます。

残るもの 通常コース for Claude Code
テンプレート/手順 定型業務7件分のプロンプト・テンプレート集 定型業務7件分の自動化手順（指示書・スキル）
成果物 研修中に作った成果物の実物 実行結果の確認手順と失敗時の戻し方
運用ルール 機密情報の扱いと出力確認の運用ルール案 扱うデータ範囲・権限の運用ルール案
展開 自部門への展開ロードマップ 自部門への展開ロードマップ

ここで見落とせないのは、通常コースが「プロンプト・テンプレート集」を残すのに対し、「for Claude Code」は「自動化手順（指示書・スキル）」と「失敗時の戻し方」まで残すと書かれている点です。素材の言葉でいえば、定型業務を「入力→処理→出力」に分解して指示書（CLAUDE.md）に書き、繰り返す処理を再利用できるスキルとして保存する——ここまでが手元に残ります。演習の実データは、AI操作のコマを含むすべてのコマで受講者の職務の実データ形式を題材にする、とあります（自社の業務データを使い、機密情報・個人情報はサンプル化）。

12時間コースと6時間ライト版はゴールが違う

もう1つ、選ぶ前に押さえたいのがコース時間ごとにゴールが違うことです。素材は両者のゴールを別々に定義しています。

項目 12時間コース 6時間ライト版
構成 4時間×3回（分割開催可） AI操作2時間＋演習4時間
ゴール（通常） 業務フローを作り直し、自部門のテンプレートと展開計画まで作る AIの操作を身につけ、各自の業務に当てはめる
ゴール（Claude Code） 定型業務の自動化手順を自部門で運用できる状態にする （同上：操作の習得と当てはめまで）
助成金 要件を満たす場合、対象となることがある 訓練時間10時間未満のため対象外

つまり「自部門の仕組みまで作り直す」なら12時間、「まず操作を覚えて各自の業務に当てはめる」なら6時間ライト版、という切り分けです。職務が混在する場合はAI操作3時間を共通で実施し、演習7.5時間を職務ごとに分けられる、とも書かれています。受講環境は受講者ごとのPCと各AI環境のアカウントが必要です。

助成金は「使えることがある」まで──保証ではない

素材が繰り返し釘を刺しているのが助成金の条件です。ここは読者が最も誤解しやすい箇所なので、素材の記述をそのまま整理します。

  • 12時間コースは、人材開発支援助成金（事業展開等リスキリング支援コース）の要件を満たす場合に対象となることがある。
  • 助成対象は雇用保険の被保険者である受講者。役員・経営者は受講できても、その分は助成対象外（受講料は同一・全額自己負担）。
  • 6時間ライト版は訓練時間が10時間未満のため対象外。
  • 訓練経費はいったん事業主が全額負担し、支給の可否・額は労働局の審査で決まる（支給を保証するものではない）。
  • 計画届は訓練開始日の6か月前から1か月前までに提出が必要。

背景として素材は、2026年8月3日以降に提出する計画届から「職務に直結したカリキュラムであること」を従来より重視する制度の見直しがある、と説明しています。「誰の・どの業務のための研修か」を明確にする流れが強まっている、という指摘です。制度の詳細・最新情報は厚生労働省の公式ページで各社が確認する必要があります。助成金の可否・額を当社が保証することはできません。

「for Claude Code」を当社の実測と突き合わせる

目玉の「for Claude Code」8コースは、プログラミング経験なしで定型業務そのものをAIエージェントに任せる手順を扱います。製造・物流・現場管理の例では「点検CSVから閾値超えを自動抽出して担当者に通知する」「日報データを集約して週報を自動生成する」が挙げられています。

ここは当社が実測で語れる数少ない領域です。当社（AIの鬼）は現在、社内業務の自動化を27本運用しており、AI秘書のブリーフィングは毎朝8:00、運用中のAI API課金は0円です。日次の自動更新は42日分の記録があり、最後に動いたのは2026-09-05（0日前）。生産量でいえば、収集済みニュース3000件・自社要約つきニュース1785件・本文取得済み1080件・記事286件が、人手を介さず毎日動いています（直近7日で記事は278本から286本へ、1日あたり約1.1本）。

素材の「入力→処理→出力に分解して指示書（CLAUDE.md）に書く」という設計思想は、当社が現に27本を回している考え方とほぼ同じで、方向性は矛盾しません。ただし——受講者が同じ成果を出せるかは素材にも当社の測定にもありません。 当社の27本は当社の環境・当社の担当が作ったもので、研修受講者に横展開したデータではありません。より詳しい突き合わせは非エンジニアがClaude Codeで定型業務を自動化する研修は、中小企業で本当に回るのか？にまとめています。助成金・職務適合の選定軸は「自社ではCopilotしか使えない」中小企業の法人AI研修は、職務×AI環境でどう選ぶのか？もどうぞ。

別報道として渡された2件は、この発表を報じていない

今回「同じ出来事の別報道」として2件のZenn記事が素材に含まれていました。1件はClaude Codeで作った「ADHD向けタスク管理アプリ」の制作記、もう1件はShopifyディレクションを自律化する「OTF（One Task Focus）」の設計解説です。

正直に書きます。この2件は、Uravationの全40コースを報じた記事ではありません。 どちらもClaude Codeやプロンプト設計を扱った別々の実践記で、今回のプレスリリースとは出来事が重なっていません。ここは寄せずに食い違いとして明示します。ただしClaude Codeで非エンジニアが実務を組む具体例としては読む価値があり、ADHDアプリの記事は「1日もかからずバイブコーディングで作った」「データを外に出さないローカル完結」を選び、OTFの記事はローカルのtask.mdをキャッシュ扱いにしてBacklog APIを唯一の正（SSOT）とする状態管理を解説しています。「指示書に定型業務を書く」の“その先”を実務者の言葉で見せる材料です。

この記事で言えないこと

  • 料金の具体額は素材本文に数字がなく、書けません。 「受講者1名あたり・税別」「人数は同一契約・同一カリキュラムの合計で判定」「助成金の有無で価格は変わらない」までが記述で、金額そのものはありません。
  • 研修の効果・定着率・工数削減率は素材にありません。 受講後にどれだけ自動化が進んだか、時間が減ったかは素材からは分かりません。
  • 助成金が実際に下りるかは労働局の審査次第で、当社は保証できません。「対象となることがある」までが素材の記述です。
  • 当社の社内自動化27本は当社環境での実績であり、研修受講者が同じ結果を出せることを意味しません。 当社は受講者の成果を測っていません。
  • 「別報道」の2件は、Uravationの発表を報じたものではありません（Claude Codeの別々の実践記）。同じ出来事を扱っていないため、両者の間の事実比較はできません。
