Claude Fable 5.1の「最大45%値下げ」は中小企業のAIエージェント費用を本当に下げるのか？

Anthropicが2026年9月1日にFable 5.1とMythos 5.1を発表し、トークン課金を一般タスクで約25%、複雑なエージェント業務で最大45%下げたとうたいました。価格は下がりますが、下がるのは「トークン単価」であって「請求額」ではありません。当社の実測（AI API課金0円）とあわせて、中小企業が請求書を上げないための順番を読み解きます。

AIの鬼 編集部2026年9月2日

Anthropicが2026年9月1日（現地時間）、AIモデル「Claude Fable 5.1」と「Claude Mythos 5.1」を発表しました。前モデルFable 5より性能を上げつつ、トークン単位の課金を一般的なタスクで約25%、複雑なコーディングなどのエージェント業務で最大約45%、キャッシュ読み取り料金を75%下げたとうたいます。ただし下がったのは「トークンあたりの単価」であって、あなたに届く「請求額」ではありません。ここを取り違えると、値下げの発表を読むほど請求書が上がります。

何が発表されたのか（素材で確認できた事実だけ）

The Verge AIとITmedia AI+の報道から、確認できた事実を並べます。

Fable 5.1は誰でも使える一般提供、Mythos 5.1は厳格な審査制で認証パートナーだけに提供される、という切り分けです。この「一般向けと審査制の二本立て」自体が今回の新しさです。

「単価が下がる」と「請求額が下がる」は別の話です

「約25%」「最大45%」はトークン単価の話です。中小企業の実際の支払いは、単価×使ったトークン量で決まります。エージェント業務は自律的にツールを何度も呼び、試行錯誤を重ねるほどトークン量が増えます。単価が45%下がっても、任せる範囲を広げてトークン量がそれ以上に増えれば、請求額は増えます。値下げの発表は、使用量が固定という前提でだけ「安くなる」話だと読むべきです。

当社（株式会社TOE / AIの鬼）は、AI検索対策やAI導入支援を売りうる立場です。その前提で自社の数字を出すと、当社が運用中のAI API課金は0円です。社内業務の自動化27本は、課金の発生しない構成で回しています。だからこそ言えるのは、「単価が下がったから乗り換える」ではなく「そもそも従量課金をいくら発生させるか」を先に決めるほうが、請求書には効くということです。トークン単価の攻防は、OpenAIとAnthropicの値下げ競争で、中小企業のAI選びは何が変わるのか？でも同じ結論に行き着きました。安くなるのは入り口の価格で、「どのモデルが自社の仕事になるか」を選ぶ責任は企業側に移っています。

値下げより先に効くのは「動かし方」かもしれません

モデルを最新版に替えることと、動かし方（ハーネス）を直すことは、別のレバーです。Writerは自社モデルではなくハーネス最適化で最大50%のコスト削減を打ち出しました（モデルを替えるより動かし方を磨くほうがAIコストは下がるのか）。今回のFable 5.1の値下げも、同じトークン量なら効きますが、任せ方を設計しないままモデルだけ替えると、増えたトークン量が値下げ分を食い潰します。

任せる範囲の設計には一次データがあります。AIエージェントへの「完全自動承認」は、なぜ習熟で約20%から40%超へ倍増したのか？で読み解いた通り、完全自動承認は新規ユーザーの約20%から習熟ユーザーの40%超へ倍増する一方、中断率も5%から約9%へ上がります。任せる範囲を広げるほどトークンも中断もエラーも増える、という順番を先に押さえてから値下げを喜ぶのが安全です。

Mythos 5.1は「監視の難しさ」も一緒に開示された

ITmedia AI+の報道によると、AnthropicはSystem Cardで、高度な推論力に伴うエクスプロイト成功率や監視困難性といったリスクも報告しています。値下げと利便性の裏で、Anthropic自身が「監視の難しさ」への懸念を開示している点は落とせません。Mythosがサイバーセキュリティ・ライフサイエンス向けに認証パートナー限定なのは、この難しさと表裏です。

なお、素材内で名称の食い違いがあります。Fable 5.1と同時発表として報じられたのは「Claude Mythos 5.1」ですが、NECが2026年9月2日にサイバーセキュリティ業務への活用を発表したのは「Claude Mythos Preview」です。両者が同じものか別物かは、素材からは分かりません。NECはProject Glasswingに参画し日本企業初のグローバルパートナーになるとしていますが、現時点では社内業務のみで、同日発表の「BluStellar Intelligent Managed Service」では使わないとしています。大企業が審査制モデルを社内検証から慎重に入れている段階です。

この記事で言えないこと

  • Fable 5.1の具体的な料金表（1トークンあたりの金額）は素材に無く、分かりません。
  • 「約25%」「最大45%」が、どのタスク構成・入出力比で測った数字なのかは素材からは分かりません。
  • 中小企業が乗り換えて請求額が実際に下がるかは、当社は測っていません（当社のAI API課金は0円で、比較対象がありません）。
  • Mythos 5.1と「Claude Mythos Preview」が同一かは分かりません。名称が食い違っています。
  • Fable 5.1のエージェント性能が、中小企業の実務でどれだけ効くかは当社では測っていません。
  • 「データ保持」への批判にAnthropicが具体的にどう対応したかは、素材からは詳細が分かりません。

まとめ

  • Anthropicは2026年9月1日にFable 5.1・Mythos 5.1を発表し、一般タスク約25%・複雑なエージェント業務最大45%・キャッシュ読み取り75%のコスト削減をうたいました。
  • 下がったのはトークン単価で、請求額は「単価×使用量」で決まります。任せる範囲を広げれば単価減は相殺されます。
  • 値下げより先に効くのは「動かし方（ハーネス）」の設計で、Writerはハーネス最適化だけで最大50%減を打ち出しています。
  • 素材内で「Mythos 5.1」と「Claude Mythos Preview」の名称が食い違っており、同一かは分かりません。
  • 当社はAI検索対策・AI導入支援を売りうる立場で、自社のAI API課金は0円です。単価より先に「従量課金をいくら発生させるか」を決めるのが、請求書には効きます。
