Anthropicが発表した常時稼働エージェント「Claude Duet」に、中小企業の経営者は何を任せ、何を自分で押すべきか？

Claude Duetは、毎朝のブリーフと日中の見張りで経営者の受信箱を代わりに読むエージェントです。ただ、まだ「研修中の秘書」の段階です。Anthropic自身が誤読を認めており、利用はPro・Max加入者のウェイトリスト制です。中小企業が先にやるべきことは導入ではなく、「何を読ませ、お金と削除と社外送信を誰が押すか」を社内ルールに書くことです。

AIの鬼 編集部2026年10月23日

結論から書きます。Claude Duetは、経営者の受信箱を毎朝要約し、日中も見張ってくれる常時稼働エージェントです。ただし2026年10月時点では、Anthropic自身が「誤読することがある」と認める研修中の秘書です。中小企業がいま決めるべきことは導入するかどうかではありません。「何を読ませるか」と「お金・削除・社外への送信を誰が押すか」です。

Claude Duetは何をするエージェントなのか

The Verge AIによると、Anthropicは専門職と小規模事業者向けのAIエージェント「Claude Duet」をリサーチプレビューとして公開しました。MetaのMuseやOpenAIのDotsに対抗する製品という位置づけです。ITmedia AI+は発表日を10月21日（現地時間）としています。Anthropicは「多忙を極め、管理し切れないプロフェッショナルや中小企業の経営者のために開発した」と説明しているそうです。基盤のモデルは「Claude Opus 5.5」で、iOS・Androidの単独アプリとWeb版のClaudeから使えます。

素材から読み取れる機能は次の5つです。

  • 毎朝、接続したアプリの重要事項を短いブリーフにまとめて届けます。ITmediaはGmailとSlackを例に挙げています。
  • 日中は接続したアプリを見張り、注意が必要なときだけメッセージを送ります。
  • 会議の日程調整のような事務作業から、数十のツールを使うダッシュボード作成、財務・売上の予測、試作、Webアプリの構築まで頼めます（The Verge）。
  • Claudeのメモリ、スキル、接続アプリを引き継ぎます。ITmediaによれば「Claude Marketplace」のコネクタとプラグインも使えます。
  • ブラウザを持つ仮想マシンで作業するため、ノートPCやスマートフォンを閉じた後も作業が続きます（ITmedia）。

The Vergeは弱点も伝えています。Anthropicは現状を「early version」と呼んでいます。スレッドを誤読したり、何が緊急かの判断を外したりする可能性があることも自ら認めています。チケット予約のような個人的な用事は「まだ強くない」そうです。

画面を操作して仕事を進めるエージェントは、当サイトの既存ツールをそのまま使いながらAIが画面を操作する時代──Grok Botは中小企業の「システム刷新」問題を解くのかでも取り上げました。Duetの特徴は、作業を代わりにやるだけではない点です。「毎朝のブリーフ」と「日中の見張り」を通じて、経営者がどこに注意を向けるかまで預かろうとしています。

互いに矛盾する記述は見つかりませんでした。気をつけたいのは次の3点です。

1つ目は地域です。「米国の加入者」という条件を書いているのはThe Vergeだけで、ITmediaとTechCrunchの素材には地域の記載がありません。The Vergeの記述どおりなら、日本の会社はいま申し込んでも使えません。日本での提供時期には、3本とも触れていません。

2つ目は機微な情報の線引きです。拒否する情報の例として、The Vergeはクレジットカード番号だけを挙げ、ITmediaは身分証明書も挙げています。さらにITmediaだけが、健康や家計などの情報は「明示的に指示した場合のみ外部に送信する」と書いています。2本を合わせると、最も厳しい階層の情報は拒否し、それ以外は指示があれば送る、という二段構えだと読めます。

3つ目はTechCrunchです。手元の素材から読み取れるのは、見出し「Claude Duet app is Anthropic's bet on agents」と提供形態だけです。機能や安全設計の記述はないため、他の2本と同じ重さでは比べられません。

守りの設計は、どの事故を止め、どの事故を止めないのか

素材に書かれた設計を、想定される事故ごとに並べます。

想定される事故 素材にある設計 残る穴
勝手な送金・削除 大きな操作の前に利用者へ承認を求める（The Verge） 「大きな操作」の範囲は素材に記載なし
カード番号・身分証の漏えい 専用の分類器と安全用のシステムプロンプトで共有の依頼を拒否（The Verge・ITmedia） 拒否の精度を示す数字は素材になし
宛先違いの送信 メール・メッセージの送信先を常にチェック（ITmedia） 人への確認か自動の照合かは記載なし
健康・家計情報の外部送信 明示的に指示した場合のみ送信（ITmedia） 指示する人の判断次第
重要な連絡の見落とし・誤読 対策の記述なし（Anthropicは誤読と緊急度の判断ミスの可能性を明言） ブリーフから漏れた連絡に人が気づく手段の記述なし

要点は表の最後の行です。承認制と分類器が止めるのは「やってはいけない操作」で、「読み違い」は止めません。送金の承認ボタンを人が押す設計でも、判断の材料がDuetの要約だけなら、誤読した要約を根拠に承認してしまうおそれがあります。朝のブリーフを信じて動く人ほど、ブリーフに載らなかった連絡に気づきにくくなります。

ITmediaが伝える「明示的に指示した場合のみ送る」も、安全を指示する人の判断に預ける設計です。たとえば「この資料を送っておいて」と頼んだとき、資料に家計や健康の情報が混ざっていないかを確かめるのは、Duetではなく頼んだ本人です。

能力より先に止める仕組みを決めるという順番は、AI企業が「ペースダウンしよう、でも中国より速く」と言い始めた──中小企業のAI導入で先に決めるべきは能力より暴走防止か？でも問いかけました。Duetはその順番を製品の側に組み込んだ例です。ただし、社内ルールの代わりにはなりません。

当社の実測と突き合わせると言えること

先に利害関係を書いておきます。株式会社TOEはAI導入支援やAI検索対策を売りうる利害関係者です。エージェント製品の評判は、当社の商売と無関係ではありません。

当社は社内業務の自動化を27本運用しており、AI秘書のブリーフィングを毎朝8:00に出しています。運用中のAI API課金は0円です。「毎朝AIからブリーフを受け取る」という形そのものは、当社では自前の仕組みで回しています。ただし、Duetと当社の仕組みを比べたことはありません。Duetはウェイトリスト制で、The Vergeの記述では米国の加入者向けのため、当社は触っていません。当社のブリーフィングで浮いた時間や、見落としの件数も測っていません。

自動化を回して言えるのは、「止まらずに動いていること」と「成果物が増えること」は別の数字だという点です。当サイトの日次の自動更新には89日分の記録があり、最後に動いたのは2026年10月22日です。一方、記事の本数は直近7日で332本のまま、1本も増えていません。この集計は本数を数えているだけで、増えなかった理由までは分かりません。常時稼働のエージェントを入れるなら、「動いているか」とは別に「何が仕上がったか」「何を見落としたか」を数える物差しを最初から用意しておく必要があります。

AIの読み違いを前提にした運用は、外部調査の数字とも重なります。Gartner（2026年5月・n=645）によると、BtoB購買担当者の51%がAIで誤情報に出会い、69%が裏取りを依頼していました。購買の場面の調査なので、Duetのブリーフとは対象が違います。それでも、AIの出力を人が確かめ直すのは例外ではない、という前提に立つ材料にはなります。

費用はどうでしょうか。リサーチプレビューはPro・Maxプランに含まれ、ITmediaによればClaudeと同様の利用制限がかかります。追加料金の記載は素材にありません。当サイトのClaude Fable 5.1の「最大45%値下げ」は中小企業のAIエージェント費用を本当に下げるのか？では、下がるのはトークン単価であって請求額ではないと書きました。プランの枠の中で動くDuetで気にすべきなのは、単価よりも「常時見張らせると枠をどれだけ使うか」です。ただ、その量は素材からは分かりません。

中小企業が導入前に書き出しておくこと

Duetが日本で使えるかどうかに関係なく、次の4つは今週中に書き出せます。製品の設計に頼らず社内ルールにしておけば、Duet、Muse、Dotsのどれを検討するときも同じ物差しで比べられます。

  1. 読ませるアプリを決めます。 ITmediaが例に挙げるGmailやSlackのように、接続はアプリ単位です。取引先の見積や社員の個人的な連絡が混ざる受信箱を、そのままつなぐかどうかを先に決めます。
  2. 人が押す操作を決めます。 Duetは送金や削除の前に承認を求めますが、それとは別に「お金・削除・社外への送信は人が押す」と社内ルールに書いておきます。
  3. 「送ってよい」と指示できる人を決めます。 健康や家計の情報は、指示すれば外部へ送る設計です。誰が、どの種類の情報について送る指示を出してよいかを決めておきます。
  4. 最初に任せる仕事を選びます。 会議の日程調整やダッシュボードの試作のように、間違えても人が後から直せる仕事から始めます。チケット予約のような個人的な用事は、Anthropic自身が「まだ強くない」としているので後回しにします。

使い始めの時期は、ブリーフと元の受信箱を人が突き合わせる時間も取ってください。素材には誤読の頻度を示す数字がないので、自社の受信箱で確かめるしかありません。エージェントに渡すものを最小にする考え方は、AIエージェントに渡したAPIキーは回収できない ― 中小企業は「渡さない」を最初に選べるのか？で書いた、「渡さない」を先に選ぶ発想と同じです。

この記事で言えないこと

  • 日本での提供時期と、日本語のメールやSlackをどこまで正しく読めるか。地域を書いているのはThe Vergeだけで、その条件は米国の加入者です。
  • 正式版の時期と、リサーチプレビュー後の料金。Pro・Maxプランの金額も素材にはありません。
  • Duetの利用が、Claude本体の利用枠とどう関係するか。ITmediaは「Claudeと同様の利用制限」とだけ書いています。
  • 分類器がどれだけ確実に拒否するか、誤読や緊急度の判断ミスがどのくらいの頻度で起きるか。精度や頻度の数字は素材にありません。
  • 承認を求める「大きな操作」の範囲。「送信先を常にチェック」が人への確認なのか、自動の照合なのか。
  • 読ませたメールやSlackの内容がどこに、どれだけの期間残るか。3本とも触れていません。
  • 複数の社員で使えるか、承認を本人以外の担当者に回せるか。
  • MetaのMuse、OpenAIのDotsとの機能・価格の比較。The Vergeが競合と位置づけているだけで、比べる材料は素材にありません。
  • 当社はDuetを触っていないため、ブリーフの質や浮く時間は測っていません。当社自身のAI秘書ブリーフィングの効果も測っていません。

まとめ

  • Claude Duetは、2026年10月21日（現地時間）にリサーチプレビューとして公開された、専門職と中小企業経営者向けの常時稼働エージェントです。基盤はClaude Opus 5.5です。
  • 利用はPro・Max加入者のウェイトリスト制で、The Vergeは米国の加入者に限ると書いています。日本での提供時期は素材からは分かりません。
  • 送金・削除前の承認、カード番号や身分証の共有拒否、送信先の確認は「やってはいけない操作」を止めますが、誤読は止めません。誤読の可能性はAnthropic自身が認めています。
  • 当社は毎朝8:00のAI秘書ブリーフィングと27本の社内自動化をAI API課金0円で回していますが、Duetとの比較も効果も測っていません。動き続けることと成果物が増えることは、別の数字で見る必要があります。
  • 導入より先に、「何を読ませるか」「お金・削除・社外送信を誰が押すか」「送ってよいと指示できるのは誰か」を社内ルールに書いておけば、製品を替えてもその準備は残ります。
