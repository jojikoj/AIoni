#開発・実装 TechCrunch AI 2026年7月22日

Glowは、AI時代のエンドポイントセキュリティにチャレンジする$1.2B評価でステルスから出現します

AI エージェントや生成AIツールが企業内に急速に浸透するなか、新しい種類のセキュリティリスクが生まれ始めている。開発者が日常的に使う ChatGPT や Claude、そして企業向けのAIエージェントが社内ネットワークに接続されることで、従来のセキュリティ対策では対応しきれない脅威が増えているというわけだ。Glow はこうした「AI時代のエンドポイント脅威」に特化したセキュリティスタートアップで、$1.2B という高い評価での資金調達によって、投資家もこのテーマの重要性を認識していることが分かる。

ここで注目すべきは、脅威の本質が従来と大きく異なる点だ。かつてのエンドポイント対策は、PC やスマートフォンといった「端末」を守ることが中心だった。ウイルス対策ソフトや VPN、ファイアウォールで、物理的な端末への不正アクセスを防ぐ構図である。しかし AI エージェント時代には、開発者が GitHub に保存したコードから API キーが漏洩したり、社員が業務システムに AI を連携させたりすることで、「人間が意識的に操作する」という従来の前提が崩れる。AI が自動で行動する領域が広がるほど、「何が起きているのか見える化」の難易度が急激に上昇するのだ。企業のセキュリティチームも、もはや「何か起きたら対応する」では対応しきれず、「AI が何をするのか事前に検知・制御する」という新しい運用を迫られている。

オフィス環境で ChatGPT を「外注先」のように使う中小企業は少なくないだろう。ただし、その LLM が企業ネットワークから何の情報にアクセスしているか、学習データとして何を送信しているか、開発部門は把握しているだろうか。セキュリティ意識の高い組織なら、API キーの管理やデータ分類を徹底しているはずだが、多くの企業ではまだグレーゾーンのままだ。AI 導入を進めるなら同時に、「このツールには何を見せて、何を見せないのか」という判断基準を整理しておくことが急務になってきた。
