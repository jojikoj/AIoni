Cloudflare Computer を読んで動かす：Durable Object の中の仮想ファイルシステム

Cloudflare がAIエージェント向けの仮想ファイルシステム「Cloudflare Computer」をMITライセンスで公開した。仮想ファイルシステムがCloudflare Durable Object という分散ステートフルワーカーの内部に構築されており、AIが作業用に書き込み・読み込みする「作業領域」として機能する。Durable Object は SQLite で状態を永続化し、その上にファイル構造が組み立てられている。記事によれば、このシステムは六つのテーブルで構成されており、ファイルの属性・位置・内容を分けて管理する設計になっている。特筆すべきは、ファイルの内容そのものを Git の内容アドレス方式（ハッシュ値）で管理し、重複排除と差分同期を同じ構造から実現している点だ。チャンク単位は512KiB に固定されている。

ここから見えるのは、「コンテナの状態喪失」という長年の悩みへの、インフラレベルの回答だ。従来のサーバーレスコンテナは、アイドル状態が続くと自動的に停止し、その間に作られたファイルは消える。AIエージェントに長時間のタスクを任せると、途中でコンテナが止まり、それまでの作業が失われる。開発中は気づかず、本番の夜間実行で初めて症状が現れるという厄介さがある。Cloudflare がここにSQLiteを介在させたのは、正本の位置をクラウド側に置くことで、コンテナ再起動時の「自動復旧」を実装するため。トレードオフとしてストレージ課金が発生するが、長時間エージェント運用には必須の実装だ。

日本の製造企画や営業事務が生成AIを使った業務自動化に踏み出すとき、「一度エージェントに任せたらちゃんと最後まで動く」という信頼感が重要になる。クラウドインフラを選ぶときに「状態の永続化」が組み込まれているかどうかを確認すること。これが単なる機能面ではなく、エージェント型ツールの実用化そのものを左右する。Cloudflare Computer はまだプレビュー段階だが、この構想が業界標準化すれば、日本の中小企業にとっても選択肢が増える。
