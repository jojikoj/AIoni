高精度GNSSモジュールのアンテナ2種を比べてみた

ハードウェア選定は、カタログ値だけでは判断できない。特に測位精度が仕事に直結する業務――配送ルート最適化、建設現場の施工管理、農業のドローン散布、重機の自動運転――では、実測データなしに進めるのはリスクが高い。wavelogy のインターン生が実施した GNSS アンテナ比較試験は、その重要性を示している。高精度なモジュール ZED-X20P に、二つのアンテナ（u-blox ANN-MB2 と Beitain BT-345AJL2）を付け替えて、開けた芝生で約30分測定した結果、水平精度（RMS 2D）では安いアンテナが優位、高度精度では高いアンテナが優位という、相反する結果が出た。また低仰角の QZSS（準天頂衛星）受信では u-blox のみが受信できたのに対し、両アンテナの平均位置の一致度は水平で約1.28m とほぼ同じだった。

AIの鬼が見るのは、この「トレードオフ」の現実だ。一般に、業者の「高い製品は総合的に良い」という説明は、疑ってかかるべき。実測から見えるのは、どの軸が自分の用途に本当に必要かという問いだ。記事では、低仰角のQZSS受信で u-blox が優位であることが指摘されている。これは日本市場に固有の要件だ。都市部や屋内での測位補強を重視するなら、QZSS対応は重い選定基準になる。一方、農山村での広範な平面測位なら、高度誤差よりRMS 2Dを優先する選定も論理的だ。つまり、安い選択肢が「間違い」ではなく、要件定義が曖昧なだけということだ。この実験は Claude Code を使って自動化されており、実測から資料化までをコードで回すプロセスの有効性も示している。

中小企業が学ぶべきは、高い製品を安易に買わないこと、そして試験費用を「無駄」と見ないことだ。1日の実測試験投資が、数年の運用効果を決める。
