#開発・実装 Zenn AI 2026年8月3日

Devin Proプラン契約後に表示される$50の正体を公式ドキュメントで徹底調査した

AI ソフトウェアエンジニア Devin の Pro プランを契約すると、アカウント設定画面に「Extra usage balance: $50.00」と表示される。多くのユーザーが「月額20ドルのプランなのに、なぜ50ドルが追加されているのか、余分に課金されたのか」と困惑する。記事の著者が公式ドキュメントを読み込んだところ、その正体は GitHub 接続時の自動付与ボーナスクレジットであり、追加課金ではないことが判明した。Pro プラン本体は月額20ドルで正しく、$50 は試用用のおまけである。使用量の消費順序は、まず Daily Quota、次に Weekly Quota を消費し、それらを使い切った後に初めてこの $50 が引かれる仕組み。実際の請求履歴（Invoice）を確認すれば、月額20ドルのみが課金されていることが確認できる。

注目すべきは、このような「混乱の発生構造」そのものだ。SaaS 企業が複数の単位（月額料金、日次クォータ、週次クォータ、ボーナスクレジット）を同時に表示するから、ユーザーが理解に困る。これは単なる UI の問題ではなく、プライシングモデルそのものの複雑化を示している。かつてのシンプルな「月額制」や「従量課金」は死に、現代の AI ツールは「ベース料金 + 枠内利用量 + 超過時の追加課金」という三層構造になった。その背景には、AI の実行コストが予測不可能であり、企業側も正確な原価計算ができないジレンマがある。

中小企業が生成AI ツールを導入するときに必ず引っかかるのが「結局、月いくらかかるのか」という見積もりの困難さだ。Devin の場合のように、見た目の料金以外に「使用量の枠」「ボーナス」「追加購入」が存在する。発注する前に必ず公式ドキュメントか FAQ で「実際の支払額がいくらになるか」を計算することをお勧めする。単価の複雑さ、ボーナスの有効期限、自動リロード機能の有無を一つずつ確認する手間が、後々の予算管理トラブルを防ぐ。
